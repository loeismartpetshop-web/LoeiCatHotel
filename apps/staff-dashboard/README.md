# Staff Dashboard App

เว็บหลังบ้านสำหรับ owner, manager, front desk, caregiver และ viewer

เริ่มพัฒนาหลัง Booking Core และ role model ผ่านการอนุมัติ

ดูรายละเอียดที่ `../../docs/06_STAFF_DASHBOARD.md`

## ต้นแบบปัจจุบัน

- `prototypes/dashboard.html` — ภาพรวมงานประจำวันและเมนูหลัก
- `prototypes/room-label-80mm.html` — ใบข้อมูลสำหรับติดหน้าห้อง

ต้นแบบใช้ข้อมูลจำลองและยังไม่เชื่อม Supabase เพื่อให้เจ้าของตรวจขั้นตอนและหน้าตาก่อนเริ่มพัฒนาระบบจริง
