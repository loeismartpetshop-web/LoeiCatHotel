# Acceptance Criteria

## Availability

- [ ] จองห้องเดียวกันในช่วงทับซ้อนไม่สำเร็จ
- [ ] การจองพร้อมกัน 2 รายไม่สามารถผ่านด้วยห้องเดียวกัน
- [ ] จำนวนแมวรวมในทุกวันทับซ้อนไม่เกิน 30
- [ ] ห้อง maintenance ไม่แสดงและจัดไม่ได้
- [ ] ห้องสำรองไม่แสดงใน customer API
- [ ] ลูกค้าต่างครอบครัวไม่ถูกจัดห้องเดียวกัน

## Capacity

- [ ] วิลล่ารับ 1-2 ตัว
- [ ] คอนโดรับ 2-4 ตัว
- [ ] คอนโดถูกแนะนำก่อน
- [ ] ลูกค้าเลือกวิลล่าได้เมื่อว่าง

## Pricing

- [ ] ไม่เกิน 6 ชั่วโมงคิด 100 บาท/ตัว
- [ ] เกิน 6 ชั่วโมงใช้ราคาค้างคืน
- [ ] แพ็กเกจ 250 และ 150 คำนวณถูกต้อง
- [ ] มัดจำเท่ากับ 50% และยอดรวมทางการเงินสมดุล
- [ ] client แก้ราคาใน request แล้ว server ไม่ยอมรับ

## Payment

- [ ] deadline เป็น 24.00 น. วันเดียวกับที่สร้าง booking ตาม Asia/Bangkok
- [ ] callback ซ้ำไม่สร้าง payment/confirmation ซ้ำ
- [ ] หมดเวลาชำระแล้วปล่อยห้อง
- [ ] ยอดคงเหลือถูกบันทึกในวันเช็กอิน

## Health Documents

- [ ] ข้ามการอัปโหลดขณะจองได้
- [ ] มีสถานะ pending และเตือนก่อนเช็กอิน 1 วัน
- [ ] พนักงานอนุมัติหน้างานพร้อมชื่อและเวลาได้
- [ ] บุคคลไม่มีสิทธิ์เปิดเอกสารไม่ได้

## Refund

- [ ] ลูกค้าสร้างได้เฉพาะคำขอ
- [ ] ระบบไม่คืนเงินอัตโนมัติ
- [ ] บันทึกผู้อนุมัติ เหตุผล และหลักฐาน

## AI

- [ ] AI ตอบห้องว่าง/ราคาจาก API เท่านั้น
- [ ] AI ไม่ยืนยัน booking เมื่อ API ไม่สำเร็จ
- [ ] AI ส่งคำขอคืนเงินให้พนักงาน
- [ ] AI ไม่เปิดเผย booking โดยไม่มีการยืนยันตัวตน
# Room Label 80 mm

- พนักงานพิมพ์ใบหน้าห้องจากรายการจองที่จัดห้องแล้วได้
- ขนาดหน้าพิมพ์เหมาะกับ Thermal POS 80 มม. และอ่านได้ในโหมดขาวดำ
- หนึ่งห้องที่มีหลายแมวแสดงชื่อและคำแนะนำของแมวทุกตัวในห้อง
- รายการจองที่ใช้หลายห้องสร้างใบแยกตามการจัดแมวจริง
- ใบพิมพ์ไม่แสดงชื่อผู้ปกครอง เบอร์เต็ม ที่อยู่ หรือยอดเงิน
- QR Code เปิดข้อมูลเต็มได้เฉพาะพนักงานที่เข้าสู่ระบบ
- เมื่อเปลี่ยนห้อง เวลา อาหาร ยา หรือข้อควรระวัง ระบบแจ้งให้พิมพ์ใบใหม่
- ระบบบันทึกผู้พิมพ์ วันเวลา และรุ่นข้อมูลที่ใช้พิมพ์
