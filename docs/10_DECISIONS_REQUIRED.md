# Decisions Required Before Production

Document Type: Decision Log  
Version: 1.0  
Status: Open

รายการต่อไปนี้ยังไม่ได้รับคำตอบหรือยังไม่ควรให้ระบบเดา

## Pricing and Time

- [x] **วิธีนับจำนวนคืนอย่างเป็นทางการ** — ตัดสินใจ 5 ส.ค. 2026: ใช้มาตรฐานโรงแรม คือ `จำนวนคืน = วันที่รับกลับ − วันที่เข้าพัก` นับตามวันที่ ไม่นับตามชั่วโมง เช่น เข้าจันทร์ ออกอังคาร = 1 คืน ไม่ว่าเข้าหรือออกกี่โมง (ยังคงกฎ BR-PRICE-001 ว่าเกิน 6 ชั่วโมงในวันเดียวกันคิดเป็นราคาค้างคืน)
- [ ] ราคารายเดือน
- [ ] ค่าดูแลพิเศษ/ให้ยา
- [ ] ค่าพาไปโรงพยาบาลและค่าใช้จ่ายฉุกเฉิน
- [ ] ราคาห้องสำรองและสิทธิ์ผู้เปิดใช้งาน

## Payment

- [ ] ผู้ให้บริการรับชำระเงิน/QR และ callback
- [ ] วิธีตรวจ payment proof หากใช้สลิป
- [ ] SLA การพิจารณาคืนเงิน
- [ ] สิทธิ์ผู้อนุมัติคืนเงินและวงเงิน

## Identity

- [ ] ลูกค้าใช้ LINE Login อย่างเดียวหรือ LINE + OTP เบอร์โทร
- [ ] พนักงานใช้ email/password, magic link หรือ SSO
- [ ] รายชื่อผู้ใช้และบทบาทเริ่มต้น

## Health and Privacy

- [ ] ขนาดไฟล์สูงสุดและชนิดไฟล์ที่อนุญาต
- [ ] ระยะเวลาเก็บเอกสารสุขภาพ
- [ ] ข้อความความยินยอมและนโยบายความเป็นส่วนตัว
- [ ] วงเงินฉุกเฉินที่ลูกค้ายินยอม
- [ ] เงื่อนไขรับแมวที่ให้ยาแต่ละประเภท

## Operations

- [ ] ยืนยันว่าแมว 1 ตัวสามารถพักห้องคอนโดได้หรือไม่ เพราะข้อมูลปัจจุบันระบุ 2–4 ตัว/ห้อง แต่กฎการจัดห้องแนะนำคอนโดก่อน
- [ ] รหัส/ชื่อภายในของห้องสำรอง 2 ห้อง
- [ ] ความจุต่ำสุด–สูงสุดของห้องสำรองแต่ละห้อง
- [ ] เวลาทำความสะอาดที่ต้อง block ห้องหลังเช็กเอาต์
- [ ] ผู้มีสิทธิ์ override เพดานหรือห้อง (ข้อเสนอ: ห้าม override เพดาน 30 ตัว)
- [ ] ขั้นตอนกรณีลูกค้ามาช้ากว่า 20.00 น.
