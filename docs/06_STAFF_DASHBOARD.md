# Staff Dashboard Specification

Document Type: Product Specification  
Version: 1.0  
Status: Ready for UX Design

## เมนูหลัก

1. ภาพรวมวันนี้
2. ปฏิทินห้อง
3. การจอง
4. เช็กอิน/เช็กเอาต์
5. งานดูแล
6. ลูกค้าและแมว
7. การชำระเงิน/คืนเงิน
8. รายงาน
9. ตั้งค่า

## ภาพรวมวันนี้

- จำนวนแมวปัจจุบัน / 30
- เช็กอินวันนี้
- เช็กเอาต์วันนี้
- รอชำระมัดจำและใกล้หมดอายุ
- เอกสารสุขภาพยังไม่ครบ
- งานอาหาร ยา ทำความสะอาด และอัปเดตภาพที่ใกล้ถึงเวลา
- คำขอยกเลิก/คืนเงินที่รอตรวจ

## ปฏิทินห้อง

- แถว: คอนโด 1-9, วิลล่า 1-7
- ห้องสำรองแสดงเฉพาะ staff mode
- คอลัมน์: วันที่
- สีสถานะ: held, pending_deposit, confirmed, checked_in, cleaning, maintenance
- คลิกเพื่อดู booking ลูกค้า แมว และข้อมูลดูแล
- เปลี่ยนห้องต้องตรวจความจุ/ทับซ้อนอีกครั้งและบันทึกเหตุผล

## สิทธิ์

| Role | สิทธิ์หลัก |
|---|---|
| owner | ทุกอย่าง รวมตั้งค่า override และอนุมัติคืนเงิน |
| manager | จัดการจอง ห้อง พนักงาน และพิจารณาคืนเงินตามสิทธิ์ |
| front_desk | สร้าง/แก้ไขการจอง เช็กอิน รับชำระ เช็กเอาต์ |
| caregiver | อ่านข้อมูลแมวและบันทึกงานดูแล/อัปเดต |
| viewer | อ่านรายงานที่ได้รับอนุญาต |

## กฎ UI

- แสดงข้อมูลที่จำเป็นตามบทบาท
- สุขภาพและเอกสารไม่แสดงในหน้าที่ไม่เกี่ยวข้อง
- ทุก override ต้องมีเหตุผล
- ห้ามแก้ยอดชำระที่สำเร็จแล้ว ให้ทำ adjustment/refund record
- ห้ามลบ booking; ใช้สถานะและ audit history
