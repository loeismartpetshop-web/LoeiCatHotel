# Project Charter: LOEI CAT HOTEL Booking System

Document Type: Project Charter  
Version: 1.0  
Status: Approved for Development  
Created: 2026-07-29

## ปัญหาที่ต้องแก้

- ลูกค้าที่โทรเข้ามาอาจไม่ได้เข้าสู่ LINE OA ทำให้ติดตามไม่ได้
- การจองยังไม่มีฐานข้อมูลห้องว่างกลางและมีความเสี่ยงต่อการจองซ้ำ
- ลูกค้าชำระเงินวันเข้าพัก ทำให้ธุรกิจเสียโอกาสเมื่อยกเลิกหรือไม่มา
- ข้อมูลสุขภาพ อาหาร ยา พฤติกรรม และเอกสารยังไม่ครบถ้วน
- พนักงานขาดระบบหลังบ้านที่เห็นข้อมูลและสถานะเดียวกัน
- ช่วงเทศกาลมีความต้องการเกินความจุและต้องบริหารห้องอย่างเป็นระบบ

## ขอบเขตระยะที่ 1

### ฝั่งลูกค้า

- เปิดหน้าจองจาก LINE OA
- เลือกวันเข้าพักและวันรับกลับ
- ระบุจำนวนแมวและข้อมูลเบื้องต้น
- เห็นประเภทห้องที่ว่างและราคา
- เลือกคอนโดหรือวิลล่า
- กรอกข้อมูลเจ้าของและแมว
- อัปโหลดข้อมูลสุขภาพภายหลังได้
- ชำระมัดจำ 50%
- รับหมายเลขและหลักฐานยืนยันการจอง

### ฝั่งพนักงาน

- ปฏิทินห้องวิลล่า 1-7 และคอนโด 1-9
- รายการรอชำระ ยืนยันแล้ว เช็กอิน เช็กเอาต์ และยกเลิก
- จัดหรือเปลี่ยนหมายเลขห้อง
- บันทึกยอดคงเหลือในวันเช็กอิน
- ดูข้อมูลอาหาร ยา สุขภาพ และข้อควรระวัง
- อนุมัติหน้างานกรณีเอกสารไม่ครบ
- รับเรื่องขอคืนมัดจำโดยไม่คืนเงินอัตโนมัติ

### ระบบกลาง

- ตรวจจำนวนแมวรวมไม่เกิน 30 ตัวในทุกวันที่ทับซ้อน
- ป้องกันห้องเดียวกันถูกจัดให้หลายครอบครัวในช่วงเวลาเดียวกัน
- คำนวณราคาและมัดจำด้วยกฎตายตัว
- ยกเลิกการถือห้องที่ไม่ชำระภายใน 24.00 น. ของวันที่จอง
- แจ้งเตือนเอกสารสุขภาพ 1 วันก่อนเช็กอิน
- บันทึกประวัติการเปลี่ยนสถานะและกิจกรรมสำคัญ

## นอกขอบเขตระยะที่ 1

- บริการกรูมมิ่ง
- สมาชิก Loei Cat Club
- ระบบคะแนนสะสม
- AI วิเคราะห์ภาพเพื่อวินิจฉัยสุขภาพ
- การคืนเงินอัตโนมัติ
- ห้องสำรองที่ลูกค้าจองเอง
- Dynamic pricing

## ตัวชี้วัดความสำเร็จ

- ไม่มีการจองห้องซ้ำ
- ไม่มีวันที่มีแมวที่ยืนยันแล้วเกิน 30 ตัว
- การจองทุกครั้งมีเบอร์โทรและช่องทาง LINE OA
- การจองออนไลน์ที่ยืนยันแล้วมีหลักฐานมัดจำ
- พนักงานเห็นข้อมูลเช็กอินและเช็กเอาต์จากระบบเดียว
- ลดรายการข้อมูลแมวที่ขาดก่อนเข้าพัก
